## الوضع الحالي (Current State)
* لا يوجد في تطبيق Flutter حالياً معالجة للبث الصوتي المباشر (Duplex Audio Streaming).
* كان التطبيق يربط سابقاً بـ Livekit ويعتمد عليه كلياً في التقاط وبث الصوت، وهو ما تم إيقافه تمهيداً لحذفه واستبداله بالمعمارية المحلية المستقلة.

---

## الوضع المستهدف / الهدف (Target State)

### 1. إلغاء شاشة الصوت الكاملة وتطهير LiveKit (Phase 3 Clean up)
* إلغاء وحذف شاشة `VoiceAgentView` بالكامل وإيقاف المسار الخاص بها.
* استبعاد وحذف مجلد البنية التحتية لـ Livekit: `sanad-client/lib/infrastructure/livekit/` بالكامل.

### 2. دمج الأزرار والتحكم بلوحة الإدخال (`AgentInputComposer`)
* إدراج زرين جديدين في لوحة الإدخال النصية:
  * **زر الإملاء الصوتي (STT Button):** عند تفعيله، يتم بث الصوت للديمون، واستقبال نصوص الترجمة الفورية جزئياً بشكل مستمر، وحقنها/تحديثها مباشرة داخل حقل النص (`TextField`).
  * **زر وضع المحادثة الصوتية (Voice Mode Button):** عند تفعيله، يتم بدء بث مقابس الصوت المستمر ثنائي الاتجاه، ويتحول مظهر لوحة الإدخال كالتالي:
    * إخفاء حقل النص وزر الإرسال.
    * إظهار مصورين صوتيين (User Waveform / Agent Waveform).
    * إظهار زر إيقاف أحمر (Hang up) للخروج من الوضع الصوتي والعودة للوضع النصي.

### 3. بث وعرض الترجمة في قائمة الشات الموحدة (Real-time Message Streaming)
* عند استقبال أحداث الترجمة الفورية في وضع الصوت ثنائي الاتجاه:
  * يتم إدراج نصوص الترجمة لصوت المستخدم وصوت الوكيل مباشرة داخل قائمة رسائل الشات الحالية كمجموعات بث متدفقة (Live Streaming Messages) في الوقت الفعلي مع تشغيل الصوت.

### 4. مشغل بث الصوت بمعدل 24kHz
* تشغيل بث الصوت المستمر المستلم بمعدل **24,000 هرتز** (24kHz Mono 16-bit) لضمان سرعة ونقاء تشغيل الصوت دون تشويه أو بطء.
