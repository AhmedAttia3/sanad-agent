## الوضع الحالي (Current State)

* **غياب آلية الاستيضاح والأسئلة التفاعلية**: عندما يعجز الوكيل الذكي (SanadAgent) عن إكمال عمله بسبب غموض أو عدم توفر بعض المدخلات أو سياق المهمة، فإنه لا يمتلك أي أداة مخصصة بالنظام تمكنه من توجيه سؤال صريح للمستخدم وتعليق الجلسة بانتظار الإجابة بشكل نظيف.
* **المشكلة الحالية**:
  * لا توجد واجهة مستخدم أو حقل إدخال Composer في فلاتر مهيأ لعرض سؤال استيضاحي موجه بشكل إلزامي ومباشر للمستخدم وإيقاف الشات العادي بانتظار رد صريح يوجه للوكيل كـ Tool Result.
  * يضطر الوكيل لتخمين الإجابات أو إخراج رسالة عادية في الشات تنتهي دون استيضاح حقيقي ولا تدخل كـ JSON result في سجل المحادثة.

## الوضع المستهدف / الهدف (Target State)

* **أداة النظام المخصصة (`system.ask_user`)**:
  * تسجيل أداة نظام جديدة باسم `system.ask_user` (أو `ask_user`) في الديمون المحلي (`LocalRuntimeCatalog`).
  * مواصفات الأداة:
    * الاسم: `system.ask_user`
    * الوصف: "Ask the user a clarifying question when you are stuck or need specific instructions to proceed. Suspends execution until answered."
    * المدخلات: `question` (String - إلزامي: السؤال الموجه للمستخدم).
  * عند تشغيل الأداة، يتم تعليق التنفيذ وإرسال حدث المقبس `ask_user_request` المرفق به السؤال للواجهة.
* **واجهة الإدخال الإلزامية المدمجة في الـ Composer**:
  * عند استقبال حدث `ask_user_request` في واجهة فلاتر (`sanad-client`)، يتم تجميد حقل الكتابة العادي واستبداله **ببطاقة مخصصة مدمجة (Prompt Input Card)** تعرض سؤال الوكيل بوضوح وحقل إدخال إلزامي لكتابة الإجابة.
  * يُمنع المستخدم من الكتابة أو الشات العادي حتى يكتب الإجابة ويضغط على زر "إرسال الإجابة (Submit Response)"، مما يولد ويبث حدث السوكت `ask_user_response` حاملاً الرد للديمون لإيقاظ الوكيل ومتابعة التفكير فوراً.
* **مؤشر الانتظار الجانبي (Sidebar Question Indicator)**:
  * إظهار أيقونة استفهام أو تنبيه صغيرة بجوار اسم المحادثة المعلقة في القائمة الجانبية للإشارة بصرياً للمستخدم بأن "هذه الجلسة متوقفة حالياً وبانتظار ردك".
